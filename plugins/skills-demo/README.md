# AI Skills

Custom Claude Code skills, one directory per skill.

- [`skills/demo-video/`](./skills/demo-video) — turns a single Playwright test into a
  client-ready demo video (real recording, smooth cursor, captions, optional
  narration and phone clip), with no manual video editing.

## Install

```
claude plugin marketplace add ansh-n-chovatiya/agent-workbench
claude plugin install skills-demo@agent-workbench
```
